# Лабораторная работа: Стек и очередь
Проверка выражений (Stack)

### Описание
Проверить корректность скобочной последовательности.
---

### Реализовано
- функцию проверки строки
- поддержку (), [], {}
- Добавить поддержку `< >`
- Вернуть позицию первой ошибки
- Подсчитать количество пар скобок в строке: `([]) -> 2`, `()[]{} -> 3`
- Проверять только круглые скобки `(` и `)`
- Проверять строку и игнорировать все символы, кроме скобок `a + (b * c) -> true`,
`if (a[2] > b) -> true`
- Вывести, каких скобок в строке больше: открывающих, закрывающих, ровно
- Определить максимальную глубину вложенности скобок
- Вывести сообщение с причиной ошибки
   Например: «лишняя закрывающая скобка» или «не хватает закрывающей скобки»
- Показывать содержимое стека после каждого шага
- Добавить возможность проверять несколько строк подряд:
`["()", "([)]", "{[]}"]` Результат: `() -> true`, `([)] -> false`, `{[]} -> true`
